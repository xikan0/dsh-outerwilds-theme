# 频谱原型 06：显示屏外观

此文保留独立原型阶段的设计与验证记录。模块已在 0.1.3 中接入主题，最终侧栏只负责显示，启停统一由设置控制；整合后的平台范围和生命周期以仓库根目录的 `NATIVE-AUDIO.md` 为准。

用户于 2026-10-10 确认采用本版波形：圆润的波峰、波谷持续向右行进，而低、中、高频所决定的强弱区域保持在各自位置。

原型 06 在原型 05 的文字与端点排版上增加显示屏背景、薄边框与柔光，继续采用已确认的原型 04 波形。

## 当前外观迭代

- 参考用户提供的「屏幕截图 2026-10-09 151723.png」，上方居中显示青色「频率：」，下一行居中显示橙黄色「Outer Wilds探险队」，两侧为青色尖括号。
- 青色使用与波形一致的 `#91dad7`，名称使用 `#efb52f`。字体沿用主题已有的 Jost 与思源黑体，字重 700；说明文字 13 px、名称 14 px。
- 波形左右端各有一条 1 px 宽、20 px 高的竖线，竖线中心始终与波形中线及端点重合。
- 移除模块内的状态灯、低中高频标签和音源文字；连接状态仍可在模块悬停提示和右侧诊断区查看。
- 背景参考用户提供的「屏幕截图 2026-10-10 113346.png」中的显示屏：深蓝底色，中央微亮，四周渐暗，并带有很淡的上方玻璃反光。
- 外框为 3 px 灰褐色渐变边框，内侧细暗边表现屏幕凹入感；保留紧凑的 8 px 外圆角。
- 文字用多层低强度光晕，波形用两层投影柔光，两端竖线同步增加光晕。字形和波形本体保持清晰，不对整块屏幕添加模糊滤镜。
- 背景和玻璃反光均为静态 CSS，不新增闪烁、动画噪点或移动扫描线。
- 字体使用仓库内的原始资源嵌入测试页，无需访问外部字体服务。

## 已确认的固定参数

- 响应增益：0.7×。
- 收束时间：250 ms（停止输入后振幅降至原来的 10%）。
- 显示高度：100%。

统一保存在 `preset.ts`。采集、绘制及测试页都读取同一组值，测试页三个参数控件已锁定，刷新后仍使用这些值。后续接入主题沿用这一基准，不重新调整波形或参数。

## 当前行为

- 音频仍分为 6 个宽频段，保留采集、响应增益和快速增强／缓慢收束的幅度包络。
- 各频段在固定的横向位置提供振幅，邻近位置用平滑插值共同决定中间的振幅分布。只在最左、最右两端收束至零，内部区域不强制回到中线。
- 用一条连续正弦波穿过这个振幅分布，公式为 `y = 中线 - 固定位置的振幅 × sin(空间相位 - 时间相位)`。只有波形相位向右行进；振幅分布不参与平移。
- 整条线约 6 个波长，每秒向右前进 1 个波长。速度按帧时间累计，不由绘制帧数决定。
- 波峰与波谷圆润过渡，取消上一版固定正负节点连接的轮廓。绘制采样间隔不超过 1 个 CSS 像素。
- 振幅插值在频段中心保持一阶和二阶导数连续；两端平滑固定在中线上，相邻频段共同影响过渡区域。
- 最大显示范围继续上下各占一半（分别为画布高度的 34%）。行波经过变化的振幅分布时，同一帧的实际最高峰和最深谷可以不同，但允许的上下振幅范围对称。
- 持续音也会流动；音乐强弱变化改变对应位置的振幅。声音停止后沿用现有收束时间，最终成为静止平线。

## 运行与查看

项目目录运行 `npm run audio:prototype`，用户自行打开 http://127.0.0.1:3093/ 。标题应为「显示屏外观 · 频谱原型 06」。服务仅监听本机，不自动打开浏览器。

`npm run audio:prototype -- --build-only` 仅重建测试页。已有服务逐次读取构建产物，刷新即可加载本轮版本；刷新后声音需要重新连接。

建议查看：

1. 播放中频持续音，波峰向右经过中间，但起伏明显的区域始终留在中间。
2. 切换低频、高频试音，比较强响应区域的位置，确认不会随波形一起漂移。
3. 连接音乐，观察流动的圆润程度、强弱分布和收束节奏；整条线两端保持固定。
4. 首页／聊天切换保留音源，断开后停止共享并收平。

## 模块与验证

- `input.ts` / `analysis.ts`：音源采集与真实频域分析，输入增益统一读取已确认参数。
- `preset.ts`：用户确认的响应增益、收束时间和显示高度，供模块与测试页共同读取。
- `spectrum-line.ts`：音频幅度包络、固定位置的空间插值，以及向右行进的连续波形。
- `prototype.tsx` / `prototype.css`：独立测试页与模拟侧栏。

TypeScript 检查和独立构建通过。内存 DOM 及替代 Audio／Canvas 检查确认：

- 固定参数的显示值及锁定状态正确；实际绘制使用 0.7× 增益，默认收束 250 ms 后振幅剩约 10%。
- 恒定输入时波形仍持续变化，追踪同一个波峰确认向右前进，位移与时间相符。
- 连续两个完整行进周期测得的各位置最大振幅一致，强响应区域没有跟随波形移动。
- 活跃绘制帧同时存在上方波峰和下方波谷，上下振幅范围保留；所有采样帧的两端固定，曲线不越出画布。
- 分别改变左右邻居会影响相邻区域内部的振幅过渡。
- 30／60／120 帧率下幅度包络的收束一致；静音最终收平，首页／聊天保留音源，断开释放轨道及音频上下文。

原型 06 的 TypeScript 检查、独立构建与内存 DOM 样式检查通过：背景和外框分层生效，边框为 3 px，字体／波形柔光规则存在，两端竖线保留；HTML、JavaScript、CSS 均正常返回。`analysis.ts`、`input.ts`、`spectrum-line.ts`、`preset.ts` 修改前后校验值一致。

独立原型的波形及固定参数已获用户确认，本轮显示屏背景、边框与柔光效果等待用户查看。尚未接入 DSH 主题，真实侧栏位置、交互和音源生命周期需要在整合后单独验收。

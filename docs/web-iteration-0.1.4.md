## 0.1.4-beta.2 · 2026-10-11

- 复现命令：`node --test tests/brand-icons.test.mjs`。修复前 CSS 解析报告两处错误，回归检查失败，对应两个失效的遮罩地址。
- 原因：原 SVG data URL 包含双引号，直接插入双引号包围的 CSS `url()` 后提前结束字符串，浏览器丢弃遮罩，只保留伪元素的矩形底色。
- SVG 加载器改为 Base64，图标地址明确使用 `data:image/svg+xml;base64,` 前缀，保留原有几何图形与透明区域。
- 回归检查使用与正式构建相同的加载器，验证 CSS 无解析错误、两个地址可解码为 SVG，且包含符号路径、不包含矩形背景。
- 修复后的类型检查、46 项测试通过；重新构建、打包并安装到 Web，保留用户本轮已有的主题设置。

用户反馈：宇宙之眼在小尺寸下细节过密，要求基于原图卡通化，逐步减少纹理、缩短与加粗放射线，再调整为从根部到末端逐渐变细。用户确认最终预览后，进入 beta.3 应用。

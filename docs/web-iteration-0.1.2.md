- 代码块正文背景：保留暖灰色，不透明度设为 75%。
- 代码块顶部语言和复制栏：保留原有暖灰色，不透明度设为 80%。
- 已发送用户消息的气泡背景：暖灰色，不透明度设为 55%。
- 只调整背景，保持文字、语法高亮、按钮和原有布局。
- 清除代码块外层与标题栏外层的重复底色，避免半透明背景叠加后变得接近不透明。
- 改动限定在主题启用后的聊天区域，输入框和菜单继续使用现有面板设置。

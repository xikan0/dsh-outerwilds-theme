## 最后一项更新讨论：插件兼容范围

用户询问现有 Market、Context 等插件的外观是否逐个适配，以及未来新插件是否需要继续添加补丁。本节记录 beta.5 的源码核对结果及建议；用户随后确认按公共面板配色统一与通用控件补查的方向执行。

- 当前采用公共 DSH 主题变量、宿主槽位与控件规则，加上少量专用页面适配。
- 当前安装的 `dshmarket@1.66.9` 主体使用 `--dsw-alias-*` 颜色变量及 DSH 公共控件；主题源码没有按 Market 包名或页面根节点编写专用补丁。
- 当前安装的 `dsh-context@0.64.0` 使用公共颜色变量，同时主题针对 `.lc-root`、`.lc-ov-page` 补充了阅读底色、透明层和独立页面背景，属于专用适配。
- 使用公共颜色与宿主组件的新插件通常能跟随配色；写死样式、自定义控件或独立页面布局可能仍需局部适配。颜色跟随不代表独立页面自动具备星空背景与透明层。
- Web 全局的部分层级背景仍为蓝灰色，设置页和 Context 局部重绑定成暖灰色，因此新插件可能继承到不同的背景层级。

建议讨论方向：优先统一公共面板配色并补查通用变量，保留必要的专用布局适配，明确兼容范围；未来插件出现具体样式问题时再局部处理。避免对所有按钮、卡片或页面强加统一形状，以免重复本轮页签状态冲突。

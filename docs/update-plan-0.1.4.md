日期：2026-10-10。

当前源码基线：0.1.3。目标版本：0.1.4。

本轮定位为介绍内容与视觉优化。以下为用户已提出的更新范围，具体文案、素材和样式要求在后续逐项细化。

2026-10-11 补充：README 保留长期有效的简要介绍，版本变化和验收记录放入 CHANGELOG；安装示例不指定版本号，更新示例使用 `--latest`。详细实现放入独立文档，README 不随每次发版例行改写。

## 推进顺序

1. 逐项明确介绍内容和视觉要求；Logo 及界面样式先确定方向。
2. 按具体要求修改，沿用现有篝火星空主题风格。
3. 界面改动按 `AGENTS.md` 完成必要检查、构建、打包、安装到 Web 并启动或重启，使用 `--no-open`。
4. 用户自行打开 Web 审查，按反馈继续迭代；实际效果验收与自动检查分别记录。
5. 根据最终效果按需调整介绍与预览图，核对 GitHub 与 npm 使用的文案和素材；具体版本变化写入 CHANGELOG。
6. Desktop 适配与正式发布按用户后续安排执行；正式收尾时统一版本信息与中文更新记录。

## 完成标准

- GitHub 与 npm 的介绍准确反映最终功能与外观，图片和链接可正常显示、访问。
- Logo 在实际使用位置清晰、比例合适，与主题风格协调。
- 侧边栏和聊天框的实际效果通过用户 Web 审查，文字可读、操作正常。
- 与改动相关的检查通过，记录实际验收范围。
- 用户确认 0.1.4 完成后，再按仓库发布流程进行正式收尾与发布。

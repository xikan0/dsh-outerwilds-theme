# 0.1.5 Web 测试记录

## 0.1.5-beta.1 · 2026-10-20

基于 0.1.4 开发，用户要求修复 bug 并美化插件 UI。具体反馈：DSH 原本为深色时，点击“星际拓荒”设置中的“启用深色主题”，按钮仍显示启用，底部提示“保存失败，已恢复已保存的设置。”；先切换为浅色再启用则可以成功。

### 保存问题

单独模拟主题服务的深色启用流程未复现保存失败。本机 DSH 为 0.2.1-rc.2，主题设置接口可写；携带当前版本的同值写入成功，携带过期版本的写入返回 `settings/conflict`。

DSH 的 ConfigForm 在拒绝后会重新读取设置并返回 false。插件原来直接结束本次写入，使已刷新版本的设置仍需用户再次触发。增加回归场景：初始为深色，切换到相同深色不会产生主题变更事件；启用请求因旧版本被拒绝并刷新后，应完成一次有条件重试。

仅当设置版本已前进、连接仍可写、设置已就绪且同字段的用户意图未改变时，重试一次。只读、未刷新版本、持续失败或已被新操作替代的请求继续保留失败处理，不移除版本校验。

该路径可复现用户描述的提示，但尚未取得用户原始失败请求的错误码。用户原环境首次启用能否恢复，仍需本轮实际复测。

### 其他修复

- 兼容旧版 `fontSize / setFontSize(px)` 和新版 `fontSizes.text / setFontSize('text', px)`。
- 恢复默认时锁定所有控件和控制器写入；完成或拒绝后恢复操作。
- 已卸载的控制器不能再执行恢复默认。

### UI 设计

色彩延续已验收主题：炭灰 `#2c2927`、暖灰 `#343130`、层次灰 `#403c3a`、正文米白 `#eee8d9`、篝火橙 `#e8a15b`、高亮奶油色 `#f6d7bc`。浅色设置页使用更深的棕色控件文字与焦点，以保持可读性。

字体沿用插件自带的 Jost 与思源黑体。标题左对齐，右侧显示主题状态；背景预览承接主题。设置采用“营地氛围 → 阅读与布局 → 声音响应”的顺序，使用细分隔线区分组别，降低普通行标题的视觉权重。保留菱形滑块，扩大箭头点击区域，数值框展示完整键盘焦点。

窄容器中说明和控件上下排列，操作按钮可换行；尊重系统减少动态效果设置。
